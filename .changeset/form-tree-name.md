The library is named FormTree. The Vue plugin is created with `createFormTreePlugin` instead of `createFormtree`, so it no longer reads like `createForm`, and its options type is `FormTreePluginOptions` instead of `FormtreeOptions`. `FormtreeProvider` and `FormtreeProviderProps` are renamed to `FormTreeProvider` and `FormTreeProviderProps`. Error messages start with `[FormTree]`, and the Vue Devtools inspector and timeline are labelled FormTree.
