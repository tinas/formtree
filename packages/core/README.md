# @formtree/core

The framework-agnostic engine of [formtree](https://form-tree.netlify.app/guide/?framework=javascript), a headless form tree in which every part of a form, from a wizard step to a single field, validates and submits on its own. Vue and React apps install `@formtree/vue` or `@formtree/react` instead.

```sh
pnpm add @formtree/core
```
